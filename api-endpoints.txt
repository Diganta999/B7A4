================================================================================
GEARUP API ENDPOINTS & POSTMAN RAW JSON PAYLOADS
================================================================================

Base URL: https://gearupshop.vercel.app/api

--------------------------------------------------------------------------------
1. AUTHENTICATION & PROFILE
--------------------------------------------------------------------------------

### [POST] Register User
* **URL:** https://gearupshop.vercel.app/api/auth/register
* **Headers:** Content-Type: application/json
* **Raw Body (JSON):**
{
  "name": "Jane Doe",
  "email": "jane.doe@example.com",
  "password": "securepassword123",
  "role": "CUSTOMER", 
  "phone": "+1234567890",
  "address": "123 Main St, Springfield",
  "profileImage": "https://example.com/profiles/jane.png"
}


### [POST] Register Provider (Alternative Role)
* **URL:** https://gearupshop.vercel.app/api/auth/register
* **Headers:** Content-Type: application/json
* **Raw Body (JSON):**
{
  "name": "Adventure Equipment Shop",
  "email": "vendor@example.com",
  "password": "securepassword123",
  "role": "PROVIDER",
  "phone": "+1987654321",
  "address": "456 Outdoor Rd, Mountain View",
  "profileImage": "https://example.com/profiles/vendor.png"
}


### [POST] Login User
* **URL:** https://gearupshop.vercel.app/api/auth/login
* **Headers:** Content-Type: application/json
* **Raw Body (JSON):**
{
  "email": "jane.doe@example.com",
  "password": "securepassword123"
}


### [GET] Get Current Authenticated Profile
* **URL:** https://gearupshop.vercel.app/api/auth/me
* **Headers:** (Note: Requires the 'accessToken' Cookie from Login)


### [POST] Logout User
* **URL:** https://gearupshop.vercel.app/api/auth/logout
